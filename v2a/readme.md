- **V2升级**

将模块主控升级为板载STM32F072主控，浑然一体，更轻巧便携。纯打字场景下，072性能与2040同样绰绰有余，而072凭借更充裕的引脚资源和更稳定低功耗，完美实现全双工通信 + 直连矩阵 + RGB幻彩灯，电路更简洁可靠。分体连线由TRS线升级为支持热插拔的TypeC线，更强的电气性能。

- **V2 Upgrade**

The module's main controller has been upgraded to an onboard STM32F072, creating a seamless, unified design that is lighter and more portable. In pure typing scenarios, the 072's performance is just as more than sufficient as the 2040's. Moreover, with its more abundant pin resources and more stable, lower power consumption, the 072 perfectly enables full-duplex communication + direct matrix connection + RGB matrix lighting, resulting in a simpler and more reliable circuit. The split connection has been upgraded from a TRS cable to a hot-swappable Type-C cable, delivering stronger electrical performance.
