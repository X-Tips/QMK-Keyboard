键位配置文件供参考，请根据自己习惯修改。

p30-vial.vil和p30-vial2.vil都是P30键盘的vial配置文件，p30-vial.vil是键盘内置的出厂默认配置。

p30-vial修饰键在下面一行，兼顾传统习惯，主要切层由拇指自然下压完成。

p30-vial2修饰键改为中间一行，所有切层键都放到下面一行，更适合进阶用户。

- 如果追求极致效率的系统化设计，建议采用A30：
- 1行超级修饰键：可统一设置MEH、HYPR、LAG等组合修饰键，将复杂的快捷键降维成“双键触发”，实现操作的高效与自动化。
- 2行对称修饰键：对称设置，全面覆盖所有字母组合快捷键,打字过程手指零移动。
- 3行拇指切层键：将拇指区打造为功能总控台，无论增加多少功能层，操作逻辑始终一致，极大降低了认知负荷。
- 扩展性极强：模块化设计使其能轻松应对复杂工作流，上限极高。
- 只要跨越初期的心理门槛，A30在复杂场景下的体验与效率拥有绝对优势。
