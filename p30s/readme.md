X.Tips P30 Mini Keyboard

* Keyboard Maintainer: X.Tips

The Bootmagic is enable, To go to bootloader press Q while plugging in.
If you edit the fireware, please keep the bootmagic feature or set a QK_BOOTLOADER keycode in your keymap file. It can put the keyboard into bootloader mode for flashing.

Every key is carefully thought out. Ditching complex techniques like Combos and Tap Dance, this is the most restrained and minimalist solution for the most hardcore efficiency (see keymaps.png):
* Zero Learning Curve: Simple tap/hold actions. Easy to memorize, no hassle.
* Direct Symbol Output: No physical Shift needed. Say goodbye to pinky strain.
* Left Thumb Press: Virtual Numpad. One-handed data entry with pure muscle memory.
* Right Thumb Press: Full Arrow Keys. Select text and move the cursor with zero hand displacement.
* Dual-Thumb Chording: Overlap left and right thumbs to toggle IME (English/Chinese) or Caps Lock.
* Full Shortcut Capability: Handle all combos involving letters, numbers, and arrow keys.
